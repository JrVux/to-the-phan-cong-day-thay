# TổThế PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng và triển khai PWA phân công dạy thay đầy đủ theo `MASTER_PROMPT.md`.

**Architecture:** React/Vite hiển thị các route nghiệp vụ và dùng Zustand làm state coordinator. Các service giao tiếp qua adapter localStorage hoặc Supabase; scoring engine thuần xử lý lọc/xếp hạng để kiểm thử độc lập.

**Tech Stack:** React 18, Vite, Tailwind CSS 3, Zustand, Vitest, Testing Library, SheetJS, jsPDF, vite-plugin-pwa, Lucide React, Supabase JS.

## Global Constraints

- Mobile-first, chiều rộng mục tiêu tối đa 430px nhưng responsive desktop.
- localStorage phải chạy hoàn chỉnh khi không có thông tin Supabase.
- Mỗi substitution luôn lưu `period_id`, `hoc_ky`, `nam_hoc`.
- Scoring weights chính xác: A 60%, B 30%, C 10%.
- Chỉ chuyển task sau khi test và build của task hiện tại đạt.
